* memory distortion

# MASTER CREATIVE DIRECTION PROMPT

Create an immersive portfolio website for a global creative director and visual storyteller.

The visual language should feel like:
a blurred emotional archive from the internet’s subconscious.

The aesthetic combines:
ambient dreamscapes,
diffused gradients,
experimental typography,
fashion-world sensuality,
and emotional futurism.

The site should feel like:
memory,
afterglow,
heat,
static,
light leaks,
dream residue,
and sensory distortion.

NOT corporate.
NOT minimal tech.
NOT clean startup UI.

Everything should feel atmospheric and emotionally charged.

---

# VISUAL LANGUAGE

Use:

* heavily diffused abstract forms
* soft glowing gradients
* bloom lighting
* blur textures
* chromatic aberration
* film grain
* glowing organic shapes
* dreamy focus shifts
* oversized ambient color fields
* soft noise textures
* translucent overlays
* emotional color bleeding
* gaussian blur layering
* floating luminous particles
* vapor-like forms
* sensory abstraction

The design should feel:
touchable,
foggy,
ethereal,
warm,
slightly surreal.

---

# COLOR SYSTEM

Primary palette:

* infrared orange
* electric pink
* ultraviolet purple
* washed lavender
* toxic yellow
* cyan glow
* fog grey

Colors should blend softly into one another.

Nothing should feel flat.

The gradients should resemble:
light through closed eyelids,
overexposed film,
heatmaps,
dream residue,
or blurred flowers through frosted glass.

---

# TYPOGRAPHY SYSTEM

Typography should contrast the softness.

Use:

* elegant stretched sans serif
* thin grotesk fonts
* handwritten italic interruptions
* poetic curved text paths
* giant atmospheric headlines
* tiny scientific annotations
* floating captions
* soft opacity typography layers

Typography should feel:
intellectual,
editorial,
sensitive,
fashion-forward,
and cinematic.

---

# WEBSITE FEELING

obsession,

slow,

# WORK SECTION

Projects appear like floating sensory worlds.

Each project:

* fills most of the screen
* has a unique ambient color atmosphere
* uses oversized typography
* feels like a campaign mood before revealing details

Hovering reveals:

* concept fragments
* cultural observations
* poetic strategic lines
* process notes

Avoid:
grid portfolios.

Instead:
make the site feel like drifting through emotional environments.

---
