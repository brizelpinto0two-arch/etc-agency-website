Create a cinematic, atmosphere-first portfolio website in Figma.
This should NOT follow traditional SaaS/web-app UI systems. Avoid standard UX patterns, boxed layouts, obvious grids, equal spacing, centered hero compositions, feature-card sections, or template-like portfolio structures.

The visual system should behave like an immersive art-directed environment rather than a website.

Think:
editorial poster system × ambient cinema × experimental fashion archive × emotional internet artifacts.

The entire interface should feel soft-focus, diffused, dreamlike, sensory, and emotionally immersive.

---

# ART DIRECTION SYSTEM

Build the visual language using:

* large-scale blurred atmospheric gradient fields
* heavy gaussian blur layers
* bloom lighting effects
* animated film grain texture overlays
* chromatic aberration
* low-opacity diffusion layers
* translucent fog overlays
* oversized ambient color masses
* soft glow blending
* dreamy color bleeding
* abstract organic forms
* VHS softness
* light leak textures
* depth haze

Visual hierarchy should come from:
scale,
contrast,
atmosphere,
and motion —
NOT containers or borders.

Typography should be the sharpest element on screen.
Everything else should feel optically diffused.

---

# COLOR SYSTEM

Avoid flat gradients.

Use atmospheric blended color fields with:

* warm infrared orange
* ultraviolet purple
* faded lavender
* washed pink
* cyan haze
* toxic yellow accents
* fog grey neutrals

Colors should interact like projected light through translucent material.

Gradients should feel:
volumetric,
foggy,
and cinematic.

# TYPOGRAPHY SYSTEM

Use typography as the structural framework.

Primary typography:

* oversized condensed grotesk
* ultra-tall editorial sans serif
* tightly tracked uppercase headings

Secondary typography:

* handwritten italic annotations
* tiny metadata labels
* fragmented floating captions
* curved/path-based text

Typography behavior:

* partially offscreen
* layered into backgrounds
* intersecting blur fields
* low-opacity stacking
* asymmetrical positioning

Avoid:
centered “hero text block” layouts.

Text should feel discovered within the atmosphere.

# HERO SECTION — TECHNICAL STRUCTURE

Build a full viewport immersive hero.

Structure:

* full-screen blurred atmospheric background
* animated grain overlay
* floating glow objects
* slow moving blur blobs
* typography emerging from fog

Composition:

* name placed asymmetrically
* rotating descriptor system underneath
* tiny annotation text in corners
* no obvious CTA buttons

Rotating descriptors:
observer / dreamer / archivist / image-maker / overthinker / collector

Animation behavior:

* slow fade transition
* opacity morph
* blur interpolation
* no typing effect
* duration: 3–4 seconds each

Mouse movement:

* subtle parallax distortion
* ambient gradient displacement
* soft cursor glow interaction

# PROJECT SECTION SYSTEM

Do NOT design project thumbnails as portfolio cards.

Instead:
create immersive visual portals.

Each project should:

* occupy irregular spatial compositions
* use atmospheric image treatments
* partially reveal content through blur
* feel like a visual memory fragment

Hover states:

* blur slightly sharpens
* typography fades upward
* glow intensity increases subtly
* metadata fades into visibility

Avoid:
hard hover transitions.

Use:
opacity interpolation,
blur reduction,
ambient scaling,
slow easing curves.
